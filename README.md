# JogoFacef1

Esse é um jogo de ataque, onde o personagem principal (“Fada”) é atacado por diversos goblins, ele possui um banco de dados que salva a pontuação do player, que é conquistada pela quantidade de ataque aos goblins que ele fizer. 

Comandos do jogo:

Movimento :Você deverá utilizar as setas para mover o jogador. (para direita, esquerda, cima e embaixo) e a visão do personagem, será seguida pelo cursor do computador. 

Ataque: Para atacar os goblins você precisa apertar com o botão esquerdo do mouse
